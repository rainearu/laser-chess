# Лазерные шахматы ⚡♟

Шахматы с лазерами в виде Telegram Mini App. На стартовом экране можно выбрать одну из трёх игр.

## Режимы

**Обычные шахматы.** Классические правила, белые против чёрных.

**Лазерные шахматы.** Фигуры могут не только ходить, но и стрелять лазером и отражать выстрелы. Луч уничтожает первую фигуру на пути, свою или чужую. Король неуязвим для лазера и останавливает луч. Есть три уровня безумия:

| Уровень | Что умеют фигуры |
|---|---|
| Только Ферзь | Стрелять может только ферзь, партия проходит быстро |
| Безумие фигур | Стреляют ферзь, ладья и слон. Один конь каждой стороны держит защитное поле 3×3, его можно бесплатно перенести на другого коня |
| Полное безумие | Всё перечисленное, плюс пешки носят зеркальные щиты: луч в центр щита возвращается назад, в край — рикошетит, с открытой стороны пешка уничтожается. За ход можно бесплатно повернуть щиты не более чем у двух пешек |

**Королевская битва.** Игра вчетвером на доске-кресте: к полю 8×8 с каждой стороны добавлены две линии, на них стоят армии. Ходят всегда в порядке Юг → Север → Запад → Восток, лазеров нет.
- *Каждый за себя.* Пока в игре трое или четверо, короля можно съесть, и съевший забирает все фигуры выбывшего. Когда остаются двое, действуют обычные правила мата.
- *Командами 2×2.* Союзники сидят на соседних сторонах (Юг и Запад против Севера и Востока), жребий решает, кто ходит первым. Союзником может быть бот, другой человек или вы сами. Фигуры союзника можно бить, кроме короля. Первого короля соперников можно съесть, его фигуры переходят союзнику. Последнего короля команды нужно заматовать.

Во всех режимах можно играть против компьютера (Легко, Средне, Сложно) или с людьми на одном устройстве. Незаконченная партия сохраняется, её можно продолжить со стартового экрана.

## Структура

| Файл | Что это |
|---|---|
| `index.html` | Вся игра: движок, бот-соперник и интерфейс. Сборка не нужна |
| `bot/bot.py` | Необязательный бот: отвечает на /start кнопкой «Играть» |
| `bot/requirements.txt` | Зависимости бота |

## Запуск

### 1. Опубликовать игру на GitHub Pages

Откройте **Settings → Pages** этого репозитория. В поле **Source** выберите *Deploy from a branch*, ветку `main` и папку `/ (root)`, затем нажмите **Save**.

Через 1–2 минуты игра откроется по адресу `https://rainearu.github.io/laser-chess/`.

### 2. Создать бота

1. Напишите [@BotFather](https://t.me/BotFather) команду `/newbot`, задайте имя и username и получите токен.
2. Добавьте кнопку игры в меню чата: `/mybots` → ваш бот → **Bot Settings → Menu Button**. Вставьте ссылку из шага 1 и назовите кнопку «Играть».
3. По желанию сделайте прямую ссылку на игру: `/newapp`, выберите бота, укажите ту же ссылку и короткое имя, например `play`. Игра будет открываться по адресу `t.me/<username_бота>/play`.

После этого бот уже работает, и сервер ему не нужен.

### 3. (Необязательно) Запустить бота с приветствием

Если нужно, чтобы бот отвечал на `/start` сообщением с кнопкой «Играть», запустите скрипт на любом сервере:

```bash
cd bot
pip install -r requirements.txt
BOT_TOKEN=<токен> WEBAPP_URL=https://rainearu.github.io/laser-chess/ python bot.py
```

## Локальная проверка

Откройте `index.html` в браузере. Внутри Telegram дополнительно работают вибрация (haptic feedback) и цвета заголовка.
